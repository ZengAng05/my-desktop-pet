# 🐾 我的桌宠

一个基于 Vite + 原生 JavaScript 的桌面宠物，包含多种表情、心情系统、随机游走、拖拽互动、自动作息、动态场景与本地存档。

## ✨ 功能总览

### 🎭 表情与心情
- **多种表情**：正常、开心、生气、疑惑、害羞、眨眼、**饿了**、**疲惫**、**饥饿**、**困倦**
- **心情系统**：周期性眨眼、随机心情切换；饱腹度低会露出饥饿表情、精力低会疲惫、快乐值低会疑惑
- **低状态提示**：当饱腹/快乐/精力偏低时，她会弹出对话框**暗示你该做什么**——饿了说“喂我点吃的嘛~”、不开心说“陪我玩一会儿嘛…”、精力低说“让我睡一会儿吧…”（每 45~90 秒提示一次，避免刷屏）
- **好感度系统**：互动累计好感度（陌生 → 熟悉 → 亲密 → 信赖 → 挚友），影响宠物心情倾向与台词语气

### 🏃 行为与动作
- **随机游走**：在屏幕内随机走动，按移动方向切换走路精灵（左/右/上下），偶尔"蹦跳"
- **拖拽互动**：按住宠物可拖到任意位置，拖完偶尔会疑惑"我怎么到这里了"
- **多种交互**：单击有反应、双击更开心、**右键生气**、**长按疑惑**
- **动作动画**：吃东西（汉堡/西瓜）、坐椅子（睁眼/闭眼打盹）、草地上躺着、走路
- **场景互动点**：游走时会主动走向**椅子**（坐下休息/打盹）和**草地**（躺着），位置可用定位工具调整

### 🌙 睡眠系统（重点！）
- **只在椅子上睡觉**：无论夜间长睡、被喊起来后重睡、还是手动小憩，她都会**先走到椅子上**才睡
- **夜间作息**：`23:00 - 次日 06:30` 自动入睡，播放入睡动画（3 帧）后停在睡眠状态；6:30 播放起床动画（4 帧）并道早安
- **睡眠中的规则**：
  - 不能移动、不能拖动、不能互动（投喂/抚摸/玩耍会被拒绝）
  - 点击她会"喊起来"：播放起床动画 → 生气/疑惑 → 吵着要睡觉 → 继续睡
  - 睡眠中精力缓慢恢复
- **说梦话**：睡眠中偶尔冒出几句梦话（每 15~40 秒，70% 概率）
- **💘 梦到男神（小概率事件）**：说梦话时有 **10%** 概率梦到男神——男神形象在宠物身边温柔浮现 + 害羞梦话（"男神…别走嘛…"）

### 🎨 视觉效果
- **动态背景**：按时段自动切换 4 种高清背景（早上/中午/下午/晚上），带淡入过渡
- **动态场景特效**：画布粒子系统——夜晚/傍晚萤火虫与星空、白天光尘
- **毛玻璃 UI**：工具栏、状态面板、定位面板、小工具菜单、时钟均为半透明毛玻璃效果（`backdrop-filter`）
- **🕐 时钟小部件**：顶部居中显示时间/日期/星期（每秒更新），点击或工具栏「时钟」可隐藏/显示，状态自动保存
- **情绪特效**：爱心/星星（开心）、怒火（生气）、问号（疑惑）、闪光（害羞）、睡觉云朵、抚摸手、球拍
- **道具展示**：投喂时显示汉堡/西瓜道具

### 🐶 狗 NPC（小团子的伙伴）
一只会自由活动的小狗（大小为团团的**一半**），可以和它互动：

| 交互 | 操作 | 效果 |
|------|------|------|
| 🖐 **抚摸** | 单击狗（或选项卡 🤚） | 狗**先跑向团团**，然后团团本体切换到**抚摸帧**（`pet_hand_left`）伸手摸它，狗播放被摸动画并说话 |
| 🎾 **扔球捡球** | **鼠标悬停狗** → 出现毛玻璃选项卡 → 点 **🎾 扔球** | 小团子做**扔球动作**，网球从团团位置朝**鼠标方向**抛物线飞出；狗跑过去捡起，**叼回放在狗面前** |
| 🐕 **跟随/自由** | 双击狗（或选项卡 🐕） | 跟随模式下狗跟着团团走；自由模式自己游走 |

- **移动动画**：移动时用**跑动画**（10 帧），停下用**站立动画**，站立时周期性**眨眼**（睁眼 ↔ 闭眼帧）
- **左右方向**：素材默认朝左，向右移动/朝向时自动**镜像**（`scaleX(-1)`）
- 狗会自己游走（自由模式），也可跟随团团（双击切换）

### 🧰 小工具菜单
工具栏「🧰 小工具」打开菜单（毛玻璃面板），宠物会互动响应：

| 小工具 | 功能 | 宠物互动 |
|--------|------|---------|
| ⏰ **闹钟** | 设置时间，到点提醒；可开/关/删多个闹钟 | 设置时“我会按时提醒主人的！”；到点大声播报“主人！闹钟响啦！”；**只有在睡觉时才会吵醒她**（会被吵醒并生气），没睡觉时只是普通提醒 |
| 📝 **备忘录** | 随手记录待办/想法，可删除 | 记录时“已经写进我的小本本啦！” |
| 📅 **日历** | 月历查看，可翻上/下月，今天高亮 | 打开时“翻开日历，每天都是新开始~” |
| ⏳ **倒计时** | 设定 时:分:秒 倒数，到 0 提醒 | 开始时“滴滴答答，时间在走~”；到点时“时间到！完成啦！” |
| 🍅 **番茄钟** | 25 分钟专注 + 5 分钟休息循环；**专注/休息时长可自定义**（点「应用」生效）；可开始/暂停/重置 | 开始时“番茄钟开始！要专心工作哦！”；休息时“番茄熟啦！快去休息~”；回来时“休息结束！继续加油工作！” |

- 数据自动保存到本地（闹钟 `your-desktop-pet:alarms` / 备忘录 `your-desktop-pet:memos`）
- 闹钟后台运行：即使关闭面板也照常提醒
- 新增小工具：在 `src/ui/widgets/` 建文件，并在 `WidgetMenu.js` 的 `WIDGETS` 注册表加一行即可

### 🛠️ 工具栏
悬停宠物显示（含 9 个按钮）：
投喂 🍗 · 抚摸 🤚 · 玩耍 🎾 · 睡觉 😴 · 状态 📊 · 时钟 🕐 · 小工具 🧰 · 定位 📍 · 重置 🔄

### 🔊 音效
Web Audio 合成点击/开心/吃东西/睡觉/生气/疑惑/抓放/唤醒/脚步声等音效，无需音频文件。

### 💬 对话系统
200+ 句台词，结合时间（早晚问候）、好感度（不同亲密度语气）、重复操作（连喂/连摸不同反应）、心情、睡眠梦话/男神梦、随机闲聊。

### 💾 本地存档
位置、状态、好感度、时钟显隐、定位位置全部自动保存，下次打开自动恢复。

## 🚀 开始使用

```bash
# 安装依赖
npm install

# 启动开发服务器（会自动打开浏览器）
npm run dev

# 打包
npm run build

# 预览打包结果
npm run preview
```

## ⚙️ 自定义（src/config/index.js）

- 宠物名字、大小：`pet.name` / `pet.size`
- 属性衰减速度：`stats.*.decayPerSecond`
- 移动速度与间隔：`movement.*`
- 眨眼/心情切换频率：`mood.*`
- **夜间睡眠**：`nightSleep`（开始/结束时间、动画帧间隔、精力恢复速度、**梦到男神概率 `crushChance`**）
- 动态特效密度：`fx.density`
- 场景互动点：`hotspots` 数组（位置、动作、台词）

### 📍 点击定位工具（不用改代码）

1. 按键盘 **`F2`** 或点工具栏的「📍 定位」按钮
2. 面板中选择元素：**椅子 / 草地**
   - 椅子：点击画面任意位置放置（粉色十字准星标记）
   - 草地：**拖拽框选**一个范围（绿色虚线框）
3. 点「完成」退出，位置自动保存，下次打开仍生效

> 💡 所有睡觉都必须在椅子上：用定位工具把**椅子**标到背景里椅子的实际位置，小团子每晚就会自己走过去睡。

## 🔧 常见问题

- **想调椅子位置**：`F2` 打开定位工具 → 选「椅子」→ 点击画面即可，不用改代码
- **想让男神梦更频繁/更稀有**：调整 `config/index.js` 里 `nightSleep.crushChance`（默认 `0.1`）
- **更换表情素材**：直接用同名文件替换 `public/assets/sprites/` 下的图片
